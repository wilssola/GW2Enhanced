# Getting help

- **Installing and using the mod:** start with the [README](README.md) ("Installing", "Updates") and the website
  https://gw2enhanced.wilssola.dev.
- **Something broke or looks wrong:** open an issue with the matching template (Bug report, Graphics calibration
  report, Feature request). Logs are off by default, so first turn on **Logs** for the feature involved in the
  overlay's Health tab, reproduce the problem, then attach that log (`GW2Translated\`, `GW2Remastered\`,
  `GW2Graphics\` or `GW2Enhanced\` in the game folder) and the overlay's Health tab status.
- **After a game patch:** the mod switches off what it cannot find and says so in the Health tab. Report it with the
  game build number; the docs `*/docs/after-a-game-patch.md` explain how parts are repaired.
- **Security issues:** never in public, see [SECURITY.md](SECURITY.md).

GW2 Enhanced is a fan project maintained in spare time and is not affiliated with ArenaNet: please do not contact
ArenaNet support about problems caused by the mod. If the game misbehaves, remove the mod (installer → Uninstall) and
check whether the problem persists before reporting it to ArenaNet.
